assignment 1
RaceDay

Project Overview

RaceDay is a web-based event management website designed for the South African road running, walking and cycling community. The website provides users with information about events and allows participants to interact with event-related content.

Part 2 – CSS Styling and Responsive Design

External Stylesheet

An external CSS stylesheet named "style.css" was created and linked to all HTML pages. Using an external stylesheet allows the website to maintain a consistent design across all pages while reducing repeated styling.

Base Styling

The website uses a CSS reset to remove default browser margins and padding. Base styling was applied to establish the font family, font size, colours, spacing and background colours.

Typography

Typography was improved using CSS properties including:

- "font-family"
- "font-size"
- "font-weight"
- "line-height"
- "letter-spacing"

Different heading sizes were used to create a clear visual hierarchy.

Desktop Layout

CSS Grid and Flexbox were used to structure the website layout. The desktop design uses multiple columns where appropriate to organise content clearly.

The website also includes:

- Navigation styling
- Buttons
- Content cards
- Forms
- Images
- Footer styling
- Borders and rounded corners
- Box shadows

Interactive Styling

Pseudo-classes such as ":hover" and ":focus" were added to interactive elements. These provide visual feedback when users interact with links, buttons and form fields.

Responsive Design

Responsive styling was implemented using media queries.

The website uses the following breakpoints:

- Desktop: More than 900px
- Tablet: 601px – 900px
- Mobile: 600px and below

On larger screens, content can be displayed in multiple columns. On smaller screens, the layout changes to a single-column structure to improve usability.

Relative units such as "%", "rem" and "em" were used where appropriate to make the website adaptable to different screen sizes.

Responsive Images

Images were styled using:

img {
    max-width: 100%;
    height: auto;
}

This ensures that images scale appropriately and do not extend beyond the available screen width.

Browser Developer Tools Testing

Browser Developer Tools were used to test the website at different screen sizes.

The website was tested using:

- Desktop screen size
- Tablet screen size
- Mobile screen size

The responsive layout, navigation, images, text and content were checked to ensure that they remain usable at different screen widths.

Screenshots of the different screen sizes are included as evidence of responsive testing.
